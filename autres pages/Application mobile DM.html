Projet personnel : Application Dantec Market

Ce projet a été réalisé seul dans le cadre d'une initiative personnelle pour l'organisation Dantec Market, située dans mon lycée (Félix Le Dantec à Lannion). L'application a été développée avec .NET MAUI en C#, dans le but de proposer une solution multiplateforme moderne, adaptée aussi bien aux ordinateurs qu'aux smartphones. Elle permet une meilleure gestion et une visibilité renforcée des activités du magasin dans l'établissement.

Technologies utilisées : .NET MAUI, C#
